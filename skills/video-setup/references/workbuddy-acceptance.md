# WorkBuddy 真实验收

本清单用于后续连接器可用时验证本套技能。这里的步骤不是执行记录。

## 独立导入与资源读取

1. 解压外层发布集合，进入workbuddy目录，先只上传video-setup-v0.1.1.zip；外层集合本身不是单技能安装包。
2. 在已安装中确认实际名称/版本，并真实读取references/project-contract.md里的“明确局部修改的批准继承”小节，不能只背SKILL正文。
3. 用实际技能目录运行scripts/project_files.py --help，保存真实输出。没有资源访问或Python时分别标阻塞，不宣布安装验收全部通过。
4. 通过后再逐个导入另五个ZIP并核对各自资源路径；保持未授权生成关闭。

## 非生成阶段

1. 确认这六个技能已被目标 Agent 读取；只读发现 LibTV 状态和当前所用 Schema。
2. 默认创建专用测试项目；若用户明确要求使用已有Smoke Test，则先保存原节点/边/revision，仅在授权目标做可回退的文本修改，结束回读原状态与无关节点；保存完整 UUID 与 revision.token，不修改客户项目或旧回归基线。
3. 建少量不运行的节点、连线与空合成节点。逐次落盘幂等键和回执；回读目标字段、项目级 edges、未改节点。
4. 只在测试项目用明确已过期的 token 验证冲突拒绝；回读确认没有脏写。
5. 用真实已有素材读时间线并做 plan/校验；空时间线仅证明结构，不算真实编辑通过。
6. 每次限定操作按prepared→真实工具调用→回执保存→succeeded/failed/unknown逐步落STATE；超时只查询，不盲重放。当前guard仍是预检，不是事务执行器。
7. 真正新开对话，仅给三份项目记录；读取同一工程、节点与已有任务，确认没有重复创建或生成。

## 获批预算后的阶段

1. 控制台核实余额、费率/免费资格和计费单位；获得具体金额与调用次数上限。
2. 生成两个最短可用镜头，保存稳定输出引用与可核验备份。不要预先指定旧报告模型名。
3. 完整播放后选中候选；只改第二镜头。核对第一镜头原输出引用/文件哈希、时间线 in/out 与实际输出内容均保留。
4. 更新必要下游合成；核对字幕、音轨、口型和相邻切点，导出真实 review render。
5. 中断后恢复 taskId；若故意断线需避免额外未受控花费，优先从已提交的普通任务恢复。未知状态不得再提交新的付费任务。

## 记录

每项存：日期、环境、skill版本、实际调用与脱敏回执、用户批准证据、通过/失败/未验证、产物引用、费用或unknown。
结构通过、生成可用、局部保留、跨会话恢复分别判定；任何缺证据的项目保持未验证。
